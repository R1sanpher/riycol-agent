# 快速入门指南

## 前置要求
- Python 3.10+
- Ollama（可选，用于本地模型）
- DeepSeek API Key（可选，用于云端兜底）

## 1. 克隆与安装
```bash
git clone <repo-url>
cd riycol-agent
pip install -e ".[all]"
```

## 2. 配置环境变量
复制 .env.example 为 .env，填写必要配置：
```bash
DEEPSEEK_API_KEY=sk-your-key-here
DEEPSEEK_BASE_URL=https://api.deepseek.com
LOCAL_MODEL_PROVIDER=ollama
```

## 3. 验证安装
```bash
python riycol.py version
python riycol.py validate
```

## 4. 启动服务
HTTP 服务器：
```bash
python riycol.py run server
# 访问 http://localhost:8080
```

Agent 模式：
```bash
python riycol.py agent run "你的任务"
```
