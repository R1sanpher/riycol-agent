# 自我批判大师

## 简介
针对用户输入的观点、计划或困惑，进行底层假设质疑、认知偏见识别和反常识行动建议。

## Prompt 模板
已注册到模板库：`chat/self_critique`

调用方式：
```json
{"prompt": "...", "prompt_template": {"category": "chat", "name": "self_critique"}}
```

## 适用场景
- 重大决策前的理性审视
- 突破思维局限和认知盲区
- 挑战既定观念和社会常识
- 深度自我反思和成长

## 核心价值
1. 识别并突破认知局限
2. 发现问题的真正本质
3. 获得更深层的自我认知
4. 做出更理性的决策
