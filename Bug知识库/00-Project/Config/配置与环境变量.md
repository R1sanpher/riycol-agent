# 配置与环境变量完整参考

## 配置文件层级

```
优先级: 环境变量 > .env > 代码默认值

文件位置:
  .env                          # 环境变量 (密钥，不提交)
  .claude/settings.json         # Hooks + MCP (项目共享)
  .claude/settings.local.json   # 权限白名单 (本地，不提交)
  .vscode/settings.json         # IDE 设置 (本地)
```

## 所有环境变量

### 本地模型

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `LOCAL_MODEL_PROVIDER` | ollama | 后端: ollama \| llama-cpp |
| `OLLAMA_URL` | http://localhost:11434 | Ollama API 地址 |
| `OLLAMA_MODEL` | gemma4-e4b | 主力模型名 |
| `MODEL_PATH` | models/qwen2.5-1.5b.gguf | GGUF 路径 (llama-cpp) |
| `N_CTX` | 2048 | 上下文窗口 tokens |
| `N_THREADS` | 8 | CPU 线程数 |

### 云端模型

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `DEEPSEEK_API_KEY` | "" | DeepSeek API Key |
| `DEEPSEEK_BASE_URL` | https://api.deepseek.com/v1 | API 地址 |

### 服务

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `PORT` | 8000 | HTTP 端口 |
| `DEBUG` | 0 | 调试模式 (1=开启) |
| `API_KEY` | "" | HTTP API 鉴权 (留空=不鉴权) |
| `MAX_CHAT_SESSIONS` | 500 | 最大会话数 (LRU) |
| `CONTEXT_ROUNDS` | 3 | 上下文轮数 |

### Telegram

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `TELEGRAM_BOT_TOKEN` | "" | Bot Token |
| `TELEGRAM_ALLOWED_USERS` | "" | 允许用户 ID (逗号分隔) |
| `TG_MODEL` | auto | 后端: auto\|deepseek\|ollama\|local |
| `TG_PROXY` | "" | 代理 (翻墙) |
| `DELAY_MIN` / `DELAY_MAX` | 1 / 2 | typing 模拟延迟 |
| `BLACKLIST_KEYWORDS` | "" | 敏感词过滤 |

### 知识库

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `USE_KB` | 1 | 启用知识库 |
| `KB_MODE` | hybrid | keyword\|vector\|hybrid |
| `EMBEDDING_MODEL` | all-MiniLM-L6-v2 | 向量模型 |
| `VECTOR_KB_PATH` | data/chroma_db | ChromaDB 路径 |

### 代理

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `TG_PROXY` | "" | Telegram 代理 |
| `NOTION_PROXY` | 同 TG_PROXY | Notion API 代理 |
| `HF_MIRROR` | https://huggingface.co | 国内镜像 |

### 日志与数据库

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `LOG_LEVEL` | info | debug\|info\|warn\|error |
| `USE_DB` | 1 | 启用数据库记录 |

## Config API (core/config.py)

```python
from core.config import CFG

# 路径
CFG.ROOT          # 项目根路径
CFG.DATA          # data/ 路径
CFG.DOCS          # data/docs/ 路径

# 模型
CFG.OLLAMA_URL    # Ollama API 地址
CFG.OLLAMA_MODEL  # 模型名
CFG.LOCAL_MODEL   # 同 OLLAMA_MODEL
CFG.MODEL_PATH    # GGUF 路径

# 服务
CFG.PORT          # 端口
CFG.DEBUG         # 调试模式
CFG.API_KEY       # 鉴权 Key

# API Keys
CFG.DEEPSEEK_KEY  # DeepSeek API Key
CFG.DEEPSEEK_URL  # DeepSeek URL
CFG.TELEGRAM_TOKEN
CFG.TELEGRAM_ALLOWED

# 代理
CFG.TG_PROXY      # TG 代理
CFG.NOTION_PROXY  # Notion 代理 (回退到 TG_PROXY)

# 数据库/知识库
CFG.USE_DB
CFG.USE_KB
CFG.DB_PATH
CFG.MAX_CHAT_SESSIONS
CFG.CONTEXT_ROUNDS

# 验证
warnings = CFG.validate()  # → list[str]
```

### 添加新配置项

```python
# 在 Config 类添加 @property
@property
def NEW_SETTING(self):
    return _safe_int(os.environ.get("NEW_SETTING", "42"), 42)

# 禁止在其他文件中使用 os.environ.get()
# 必须通过 CFG 单例访问
```

## 权限配置 (.claude/settings.local.json)

```json
{
  "permissions": {
    "allow": [
      "Read", "Write", "Edit", "MultiEdit",
      "Bash(python:*)", "Bash(pytest:*)",
      "Bash(git:status)", "Bash(git:diff)",
      "Bash(git:add)", "Bash(git:commit)",
      "WebSearch", "WebFetch"
    ],
    "deny": []
  },
  "acceptEdits": true
}
```

### 权限规则
- `Bash(cmd:*)` — 通配符匹配子命令
- `deny` 优先级高于 `allow`
- 破坏性命令始终确认 (`rm -rf`, `git push --force`)
- Claude Code 读取 `.claude/settings.local.json` (不是根目录的)

## Hooks 配置 (.claude/settings.json)

```json
{
  "hooks": {
    "UserPromptSubmit": [
      // 每次用户输入时执行
      {"type": "command", "command": "powershell -File ..."}
    ],
    "PostToolUse": [
      // 工具调用后执行
      {"matcher": "Bash", "hooks": [...]}
    ]
  }
}
```

### 当前已配置的 Hooks
| 钩子 | 触发时机 | 脚本 |
|------|---------|------|
| UserPromptSubmit | 每次用户输入 | activator.ps1 + session-sync.ps1 |
| PostToolUse(Bash) | Bash 命令后 | error-detector.ps1 |
| PostToolUse(Agent) | Agent 调用后 | 流水线提示 |
