# riycol-agent 项目架构总览

## 一句话描述
多Agent AI 服务平台：本地 Ollama 推理 + Telegram Bot + HTTP API + 知识库 + 微调管道

## 技术栈

| 层 | 技术 |
|----|------|
| 语言 | Python 3.10+ |
| LLM 后端 | Ollama (qwen3:8b) / DeepSeek API / llama-cpp GGUF |
| 数据库 | SQLite WAL + threading.Lock |
| 向量存储 | ChromaDB (SentenceTransformer) |
| HTTP | stdlib HTTPServer + SSE + WebSocket |
| 前端 | 原生 HTML/CSS/JS (SSE + WS 双模式) |
| 测试 | pytest (148+ 用例) |
| Lint | ruff (E501 ignored) |
| CI | GitHub Actions (Windows+Ubuntu, Python 3.10-3.12) |

## 三层架构

```
┌──────────────────────────────────────┐
│         入口层 (Entry)               │
│  riycol.py → cli/riycol.py          │
│  15 个子命令                         │
├──────────────────────────────────────┤
│         核心层 (Core)                │
│  config db logger memory tools      │
│  retry planner reflection prompt    │
│  token model_router sync_*          │
├──────────────────────────────────────┤
│         插件层 (Plugins)             │
│  server  │  telegram  │  agent      │
│  HTTP    │  Bot       │  Multi-Agent│
└──────────────────────────────────────┘
```

## 数据流

```
用户输入 (CLI/API/TG/Web)
    ↓
model_router.route() → 选择后端
    ↓
Agent.act() / act_with_react() / act_with_plan()
    ↓
raw_llm_call() → [DeepSeek|Ollama|llama-cpp]
    ↓
Tool.execute() (可选: read_file, db_query, search_kb...)
    ↓
回覆 → memory_store.save() + DB.add_msg()
```

```
core/planner.py        ← model_router, agent(raw_llm_call)
core/reflection.py     ← prompt_manager, agent(raw_llm_call)
core/sync_notion.py    ← config
core/sync_session.py   ← memory_store
plugins/agent/         ← ALL core modules
plugins/server/        ← agent, kb, vector_kb
plugins/telegram/      ← agent, model_router
```
