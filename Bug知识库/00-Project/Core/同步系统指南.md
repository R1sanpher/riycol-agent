# 同步系统完整指南

## 两条同步通道

| 通道 | 方向 | 技术 |
|------|------|------|
| Notion ↔ 本地知识库 | 双向 | Notion API + 代理 |
| 跨会话状态 | 多会话共享 | memory_store + hooks |

---

## Notion ↔ 本地同步

### 配置

```bash
# .env
TG_PROXY=http://127.0.0.1:7897     # Clash Verge 代理
NOTION_PROXY=                       # 默认回退到 TG_PROXY

# .vscode/settings.json
{"notion.apiKey": "ntn_xxx"}
```

### CLI

```bash
# 从 Notion 拉取到本地 Bug知识库/
python riycol.py sync notion --direction pull

# 推送本地变更到 Notion
python riycol.py sync notion --direction push

# 双向同步
python riycol.py sync notion --direction bidirectional

# 全同步 (Notion + 会话)
python riycol.py sync all
```

### 程序化

```python
from core.sync_notion import pull, push, sync

# 拉取
n = pull("riycol agent 库(知识 数据)")
print(f"Pulled {n} pages")

# 双向
r = sync()
print(f"Pulled {r['pulled']}, Pushed {r['pushed']}")
```

### 数据格式
- Notion 页面 → 本地 `.md` (YAML frontmatter + Markdown)
- 自动跟踪 `notion_id`, `last_synced`, `status: synced`
- 文件名自动消毒 (`_safe_filename`)

## 跨会话状态同步

### 工作原理

```
Session A                    Session B
    ↓                            ↓
memory_store.put()          memory_store.get()
("_system",                  ("_system",
 "cross_session_state")      "cross_session_state")
    ↓                            ↓
        共享 SQLite 数据库
    (data/database.db)
```

### CLI

```bash
# 注册跨会话任务
python riycol.py sync session --task "正在实现 XX 功能"

# 查看状态
python riycol.py sync status
# → Session: last_updated=15:30:00
# → Active tasks: 2
# →   [in_progress] 正在实现 XX 功能
# →   [pending] 等待审查 PR #42
```

### 程序化

```python
from core.sync_session import (
    sync_task, get_active_tasks, update_context,
    get_session_state, snapshot
)

# 注册任务
tid = sync_task("修复 memory_store TTL bug", "in_progress")

# 更新状态
sync_task_status(tid, "completed", "已修复，测试通过")

# 获取活跃任务
for t in get_active_tasks():
    print(f"[{t['status']}] {t['task']}")

# 跨会话传递上下文
update_context("handoff_note", "请继续审查 core/retry.py")

# 查看快照
snap = snapshot()
print(snap)  # {has_state, last_updated, active_tasks, keys}
```

### Hook 集成

每次用户输入时自动执行 (`.claude/settings.json`):

```json
{
  "UserPromptSubmit": [{
    "hooks": [{
      "type": "command",
      "command": "powershell -File .claude/hooks/session-sync.ps1"
    }]
  }]
}
```

效果:
```
[SYNC] 2 active tasks across sessions:
  [in_progress] 修复 memory_store TTL bug
  [pending] 等待审查 PR #42
```
