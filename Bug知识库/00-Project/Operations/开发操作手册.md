# 开发操作手册

## 环境准备

```bash
# 1. 安装 Python 3.10+
# 2. 克隆项目
git clone <repo> && cd riycol-agent

# 3. 复制并编辑配置
copy .env.example .env

# 4. 安装依赖
pip install ".[all]"     # 全量安装

# 5. 验证
python riycol.py validate
```

## 环境变量 (.env)

```bash
# === 本地模型 ===
```

## 日常开发流程

```bash
# 1. 修改代码
# 2. 运行相关测试
pytest tests/test_agent.py -v

# 3. Lint 检查
python -m ruff check core/ plugins/ cli/ tests/ --ignore E501

# 4. 运行全部核心测试
pytest tests/ -v --ignore=tests/test_e2e.py --ignore=tests/test_handler.py

# 5. 配置检查
python riycol.py validate
```

## 添加新工具

1. 在 `core/tools.py` 中定义函数
2. 创建 `Tool` 实例加入 `_builtin_tools` 列表
3. 四要素：`name_for_human`, `name_for_model`, `description`, `parameters`

```python
def tool_my_func(param: str) -> dict:
    """My new tool."""
    return {"result": param}

_builtin_tools.append(
    Tool("my_func", "Description for model",
         {"type": "object", "properties": {
             "param": {"type": "string", "description": "Param desc"}
         }, "required": ["param"]},
         tool_my_func, name_for_human="My Function")
)
```

## 常见问题

| 问题 | 解决方案 |
|------|---------|
| Ollama 不响应 | `ollama list` 确认运行中；加载 `config/ollama-env.ps1` |
| Notion API 超时 | 确认 Clash Verge 运行 + `TG_PROXY` 已设 |
| 测试卡住 | 跳过 e2e/handler: `pytest tests/ -v --ignore=tests/test_e2e.py --ignore=tests/test_handler.py` |
| Lint 报错 | `python -m ruff check ... --fix` 自动修复 |
| DB 损坏 | 备份后删除 `data/database.db`，重启自动重建 |
| 模型下载失败 | 设置 `HF_MIRROR=https://hf-mirror.com` 国内镜像 |
