core/retry.py:

- RetryPolicy dataclass — 声明式配置: max_attempts/base_delay/max_delay/backoff/jitter

- @retry装饰器 — 指数退避(delay * 2^n) + 随机抖动(0.75-1.25) + functools.wraps保签名

- 已应用于: _call_deepseek(3次) / _call_ollama(3次) / _raw_call(3次)

CircuitBreaker 三态断路器:

- closed -> open: failure_count >= failure_threshold时跳闸

- open -> half_open: recovery_timeout秒后自动转换

- half_open -> closed/open: 根据half_open_limit次调用结果决定

- CircuitOpenError: 断路器开放时拒绝调用

model_router 三路断路器:

- deepseek: failure_threshold=5, recovery=30s

- ollama: failure_threshold=3, recovery=45s

- local: failure_threshold=3, recovery=60s

- API: record_backend_success(backend) / record_backend_failure(backend) / get_circuit_breaker(backend)

Agent 错误处理增强:

- 错误回复带 _error标记，_save_memory()自动过滤

- _strip_error_meta() 发送LLM前去内部标记

- 断路器开放时返回友好消息而非异常
