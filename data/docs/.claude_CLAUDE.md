# .claude/ — 项目级 Claude Code 子代理配置

## 子代理

### tg-bot
调试 Telegram Bot 相关问题（消息收发、网络错误、模型路由）。
- 关键文件：`plugins/telegram/bot.py`, `plugins/telegram/ai.py`
- 运行命令：`python riycol.py run telegram`
- 日志关键字：`Telegram msg`, `Telegram reply`, `TG AI backend`
- 架构：ThreadPoolExecutor (max 10) 并发处理更新，消息超 4096 字符自动分段
- 已知问题：Ollama `extra_body` 不兼容、gemma4 50s/条、SSL 超时重试

### agent-debug
调试 Agent Swarm / 统一 Agent 相关问题。
- 关键文件：`plugins/agent/__init__.py`
- 运行：`python riycol.py agent run "<task>"`
- 持久记忆：`core/memory_store.py` (SQLite `agent_memory` 表，支持 db 注入测试隔离)
- 测试：`pytest tests/test_agent.py -v`

### kb-mgmt
管理 Bug 知识库和 Self-Improvement 学习记录。
- 知识库：`Bug知识库/` + `Bug知识库/Bug索引.md`
- 学习记录：`.learnings/ERRORS.md`, `.learnings/LEARNINGS.md`, `.learnings/FEATURE_REQUESTS.md`
- 写入工具：`from core.obsidian_writer import obsidian`
- 注意：`obsidian.write_note()` 会自动消毒 filename（`Path(name).name`），无需手动处理

### model-ops
模型运维（Ollama 模型管理、性能优化、Modelfile）。
- Ollama API：`http://localhost:11434`
- 锁定模型：`gemma4-e4b`
- Modelfile：`config/gemma4-opt.Modelfile`
- 环境变量脚本：`config/ollama-env.ps1`
- 路由：`core/model_router.py`（可用性结果缓存 30s TTL）
- 工具查询 DB 时使用 `sqlite3.set_authorizer()` 白名单

### server-debug
调试 HTTP 服务器、WebSocket、前端相关问题。
- 关键文件：`plugins/server/handler.py`, `plugins/server/ws_handler.py`, `static/index.html`
- 运行：`python riycol.py run server`
- 并发安全：`chat_lock`（公开）保护 `chat_history`，WS 和 HTTP 处理器均需持有
- 路径安全：必须用 `Path.relative_to()` 验证路径包含，不可用 `str.startswith()`
- 前端：SSE + WebSocket 双模式，WS 断开自动重连 3s，Markdown 渲染器已预转义 HTML
- Origin 验证：`ws_handler.py` 白名单 `localhost` + `127.0.0.1`

## 常用命令

```bash
pytest tests/ -v                                    # 全部测试 (98 用例)
pytest tests/test_agent.py -v                       # 单文件
pytest tests/test_agent.py::TestAgent::test_act -v  # 单测试
ruff check .                                        # Lint
ruff check --fix .                                  # Lint 自动修复
python riycol.py validate                           # 配置检查
python riycol.py agent list                         # 查看 Agent
python riycol.py run server                         # 启动 HTTP 服务
python riycol.py run telegram                       # 启动 TG Bot
python riycol.py model list                         # 模型列表
python riycol.py scheduler                          # 调度器状态
```
